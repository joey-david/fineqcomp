# Known-payload control

[Instrument validation](instrument_validation/) is the completed synthetic
control in Appendix A.5. The task assigns sixteen labels to family/item pairs,
with known source information and fixed training budgets.

The corrected prequential code orders the source conditions; the adapter rates
do not follow a simple source-length ordering. This is a negative result for
a corpus-only rate law, not evidence of a universal information-to-rate rule.

The tables include the original mixture code and the corrected switch code.
The latter was recomputed from saved probabilities; the study note records
that distinction. The runner is `fineqcomp.studies.information_scaling`, with
`configs/payload/information_validation.yaml`.
